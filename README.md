## Hi, I'm Sahar

I'm a data scientist based in London. I have an **MSc in Data Science (Distinction)** from Queen Mary University of London and a **BSc in Economics & Data Science (First-Class Honours)** from Royal Holloway.

I like problems where the modelling and the engineering both matter: building a model, testing it honestly, and then running it reliably. For my MSc dissertation I asked when a deployed credit-risk model should be recalibrated or replaced, when the loan outcomes that show it has degraded only arrive months later. I built and evaluated a policy to answer that, then ran it as a monthly job on Google Cloud.

I'm looking for **junior data scientist / machine learning roles** in London.

### Selected work

- **[drift-aware-credit-risk-mlops](https://github.com/SHR-IM/drift-aware-credit-risk-mlops)**: my MSc dissertation. An XGBoost default model on 1.18M Lending Club loans, with drift monitoring (PSI with Benjamini–Hochberg correction, JSD), a champion–challenger promotion gate and block-bootstrap non-inferiority tests. Replayed month by month on Cloud Run + BigQuery, matching the offline run for 36/36 cohorts.
- **[spark-big-data-analytics](https://github.com/SHR-IM/spark-big-data-analytics)**: PySpark at scale. 9.9M Expedia searches, 3M Amazon reviews, a 22.4M-trip NYC taxi graph (GraphFrames: PageRank, connected components, shortest paths) and a Structured Streaming job with watermarks and checkpoint recovery.
- **[cifar10-cnn-pytorch](https://github.com/SHR-IM/cifar10-cnn-pytorch)**: a multi-branch CNN built from scratch in PyTorch, taken from 34% to 91.8% CIFAR-10 test accuracy in five controlled stages.
- **[policy-evaluation-causal-inference](https://github.com/SHR-IM/policy-evaluation-causal-inference)**: does free tutoring raise test scores? Difference-in-differences, fixed effects, IV and fuzzy regression discontinuity on a 40,000-child panel in R, and why the methods disagree.
- **[cloud-econ-insights](https://github.com/SHR-IM/cloud-econ-insights)**: a Flask REST API (group project) that stores economic indicators and pulls live values from the World Bank API, with hashed API keys, per-user data isolation, automated tests and a Docker image for Cloud Run.
- **[web-scraping-portfolio](https://github.com/SHR-IM/web-scraping-portfolio)**: a Scrapy crawler for a full Stack Exchange forum, an XPath scraper for Wikipedia country data, and a breadth-first search route finder over a scraped border graph.
